# 数据库配置说明

## 概述
为了方便管理数据库连接配置，已将所有分散在各个文件中的数据库连接代码集中到了 `db_config.php` 文件中。

## 配置文件位置
```
Dev/chatRoom/db_config.php
```

## 修改数据库配置
只需要修改 `db_config.php` 文件中的以下常量：

```php
// 数据库配置参数
define('DB_HOST', 'localhost');     // 数据库主机
define('DB_USER', 'root');          // 数据库用户名
define('DB_PASS', '123456');        // 数据库密码
define('DB_NAME', 'test');          // 数据库名
```

## 已修改的文件列表
以下文件已经修改为使用集中配置：

1. `chat.php` - 聊天页面
2. `user.php` - 用户管理页面
3. `room.php` - 房间页面
4. `auto_login_bridge.php` - 自动登录桥接
5. `update_room_stats.php` - 统计数据更新
6. `api/chatroom_api_ultra_simple.php` - 聊天室API
7. `api/upload.php` - 文件上传API

## 优势
- **集中管理**：只需修改一个文件即可更改所有数据库连接
- **便于维护**：避免在多个文件中重复修改
- **减少错误**：统一的连接方式，减少配置错误
- **安全性**：可以轻松更改数据库凭据

## 使用方法
1. 打开 `db_config.php` 文件
2. 修改对应的数据库参数
3. 保存文件
4. 所有相关功能将自动使用新的数据库配置

## 注意事项
- 确保新的数据库配置信息正确
- 修改后请测试所有功能是否正常
- 如果需要恢复，备份文件中还保留了原始的连接代码
