# 聊天室链接功能说明

## 功能概述
现在在聊天室中发送消息时，如果消息包含链接，系统会自动识别并以胶囊样式显示，支持自定义链接显示文字功能。

## 功能特点

### 🔗 自定义链接文字
支持使用 `[自定义文字]链接地址` 的格式来自定义链接显示的文字：
- `[测试链接]http://test.com` - 显示"测试链接"，点击跳转到 http://test.com
- `[查看文档]https://docs.example.com` - 显示"查看文档"
- `[电子合同]https://contract.example.com` - 显示"电子合同"

### 🎯 自动链接识别
同时支持普通链接格式：
- `http://` 开头的链接
- `https://` 开头的链接  
- `www.` 开头的链接

### 🎨 统一胶囊样式
所有链接都使用统一的紫色胶囊样式，通过自定义文字来区分链接类型。

### 🖱️ 点击跳转
- 点击链接时会弹出确认对话框
- 确认后在新窗口打开链接
- 安全防护，避免恶意链接

## 使用示例

### 自定义文字链接：
```
请查看[电子合同]https://example.com/contract.pdf
访问[公司官网]https://www.example.com
下载[用户手册]https://docs.example.com/manual.pdf
查看[空白链接]https://test.com
```

### 显示效果：
- `电子合同` （紫色胶囊，点击跳转到合同链接）
- `公司官网` （紫色胶囊，点击跳转到官网）
- `用户手册` （紫色胶囊，点击跳转到文档）
- `空白链接` （紫色胶囊）

### 普通链接：
```
官网地址：https://www.example.com
测试链接：http://test.com
```

### 显示效果：
- `https://www.example.com` （紫色胶囊，显示完整链接）
- `http://test.com` （紫色胶囊，显示完整链接）

## 样式说明

### 链接外观
- **形状**：圆角胶囊状
- **大小**：小号字体，紧凑设计
- **动效**：悬停时轻微上浮，点击时有按压效果
- **文字截断**：过长文字自动截断并显示省略号
- **渐变**：使用统一的紫色渐变背景

### 颜色方案
- **统一样式**：紫色渐变 (#667eea → #764ba2)
- **悬停效果**：深紫色渐变 (#5a6fd8 → #6a4190)

## 注意事项

1. **自定义格式**：使用 `[文字]链接` 格式，中括号和链接之间不能有空格
2. **空白文字**：如果 `[]` 内为空或只有空格，会显示完整链接地址
3. **链接格式**：确保链接格式正确（http://、https:// 或 www.开头）
4. **特殊字符**：链接和自定义文字中的特殊字符会被自动转义
5. **长度限制**：自定义文字过长会被截断并显示省略号
6. **安全提醒**：点击链接前请确认来源安全

## 测试方法

可以发送以下测试消息验证功能：

```
自定义文字测试：[测试链接]http://test.com
自定义空白测试：[]https://www.baidu.com
普通链接测试：https://www.google.com
无协议测试：www.example.com
多链接测试：访问[官网]https://www.baidu.com或者https://www.google.com
```

发送后应该看到：
- "测试链接" 胶囊
- "https://www.baidu.com" 胶囊（因为[]内为空）
- "https://www.google.com" 胶囊
- "www.example.com" 胶囊
- "官网" 和 "https://www.google.com" 两个胶囊
